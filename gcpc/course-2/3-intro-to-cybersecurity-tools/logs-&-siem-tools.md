# Notes
## Logs
- record of an event that occurs on a system/network
### Common Log Sources
#### Firewall Logs
- record of attempted/established connections for incoming traffic
- additionally, includes outbound traffic leaving the network
#### Network Logs
- record of all devices that enter/leave the network
- Additionally records connections between these devices and services provided by the network
#### Server logs
- record of events that is related to services provided via servers such as: emails, websites, file sharing
- events may include: login, passwords, and username requests
### SIEM
- Security Information and Event Management
- An application that aggregates and analyzes log data to monitor critical activity in an org
- stores all log data in a centralized location
- offers real time alerts
