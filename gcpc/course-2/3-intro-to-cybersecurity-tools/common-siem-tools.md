# Notes
## SIEM Tool Types
### Self-Hosted
- ensure most control over private data
- requires most upkeep by organization since no third party is used
### Cloud-Based
- managed by SIEM providers
- avoids the maintenance cost associated with Self-hosted
### Hybrid
- leverages the privacy of self-hosted with the utility of a cloud system
