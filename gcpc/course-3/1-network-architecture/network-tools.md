# Notes
## Network Tools/Devices
### Hub
- unintelligent, broadcast all data through network
### Switch
- intelligent, only passes data to right device using addresses
- improves security/network performance
### Router
- very intelligent connects multiple networks together
### Modem 
- connect router to the internet
### Firewall
- monitors egress/ingress traffic/can restrict/block traffic
### Virtualization Tools
- simulate these hardware devices in the cloud
