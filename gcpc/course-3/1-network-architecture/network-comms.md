# Notes
## Data Packets
- basic unit of data that travels between one device and another on a network
### Format of Data Packets

| Header | Body | Footer |
| ------ | ---- | ------ |
|        |      |        |

#### Header
- IP Address/MAC Address/Protocol Number
#### Body
- Contains the actual message to be delivered
#### Footer
- Signals the message has ended
## Bandwidth 
- The amount of data a device receives every second
Speed
- The rate at which data packets are received or downloaded
## Packet Sniffing
- The practice of capturing and inspecting data packets across a network
