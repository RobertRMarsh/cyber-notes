# Notes
## TCP/IP Model
- Standard model used for network communication
### TCP 
- Transmission Control Protocol
- internet communication protocol which allows two devices to form connections/stream data
- makes sure data arrives in the correct order and checks that it arrives
### IP
- Internet Protocol
- standards used for routing/addressing data packets as the travel between devices on a network
