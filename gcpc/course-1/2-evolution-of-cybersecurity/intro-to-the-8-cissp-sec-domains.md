# Notes
## Intro to the 8 CISSP Domains
### Security and Risk Management
- Defines security roles/objectives
- Risk mitigation
- Compliance
- Business continuity
- Law
### Asset Security
- Securing digital/physical assets
- Handling data's
	- Storage
	- Maintenance
	- Retention
	- Destruction 
### Security Architecture and Engineering
- Optimizing data security 
- Ensuring the following are in place
	- Effective tools
	- Systems
	- Process
### Communications and Network Security 
-  Managing and securing 
	- Physical network 
	- Wireless communications
### Identity and Access Management
-  Keep data secure
-  Ensure users follow policies that 
	- Manage physical/logical assets like
		- Office spaces
		- Networks
- Validate users identities
	- Setting up keycard access
### Security Assessment and Testing
- Security control testing
- Conducting security audits
- Collecting analyzing data
### Security Operations
- Conducting investigations/implementing preventative measures 
### Software Development Security
-  Using secure coding practices
